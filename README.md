# TCPnoobs
TCPnoobs is a beginner-friendly educational website focused on helping people in Bulgaria understand networking concepts in a simple and accessible way.
The goal is to make networking less intimidating by breaking down core internet and networking protocols into easy-to-read explanations.
The idea of this project is to help beginners in Bulgaria get into Networking more easily and build a solid foundation in topics like:
- IP (Internet Protocol)
- TCP (Transmission Control Protocol)
- UDP (User Datagram Protocol)
- DNS (Domain Name System)
- NAT (Network Address Translation)
Everything is explained in a simple, structured way without unnecessary complexity.
- Current State:
  Frontend only (HTML + CSS + basic JS)
  Focused on educational content
  No backend (intentionally)(for now)
  No user system or database

The project is currently centered around documentation and protocol explanations rather than interactivity.

- Add more networking topics (HTTP/HTTPS, TLS, Sockets, WebSockets)
- Improve UI/UX and animations
- Possibly introduce interactive learning features
- Expand content depth over time

Keep it simple. Keep it understandable.  
Networking doesn’t have to feel complicated.
